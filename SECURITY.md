# Security policy

RequestLab 0.1 is an engineering beta. It is not independently audited or approved for handling production secrets.

Please use the repository's GitHub **private vulnerability reporting** channel if enabled. If it is not enabled, ask the repository owner to enable it; do not post exploit details, credentials, customer data, or payment references in a public issue. There is no invented security mailbox or guaranteed response SLA.

Include affected commit/version, OS/runtime, reproduction steps using non-sensitive fixtures, impact, and a suggested fix when possible. Do not test against another user's workspace or a deployed system without authorization.

Supported development line: the current 0.1 branch. No older release has a security-support commitment. See [threat model](docs/security/THREAT_MODEL.md) for trust boundaries and release gates.
