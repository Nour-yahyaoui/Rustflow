# Changelog

## 0.1.0 — 2026-11-01 — Engineering beta (unreleased)

- Introduced RequestLab from the initial Rustflow repository.
- Added React/Vite request workspace, real Node development transport, SQLite preview persistence, collections, environment variables, bounded response inspection, and portable exports.
- Added offline Monaco editing and worker-isolated QuickJS assertions/collection runs.
- Added browser/native WebSocket transports and a documented OpenAPI JSON subset.
- Implemented Rust/Tauri HTTP, storage/vault, cancellation, and WebSocket command sources; compilation remains unverified here.
- Added Next.js portal, PostgreSQL/Fastify API, verified-email accounts, role-based workspaces, versioned change API, comments, manual billing, and authorized administration.
- Added integration/browser tests, CI and unsigned build workflows, container configuration, and deployment/security documentation.

Not a production release. Desktop background cloud sync, OAuth, full import compatibility, mocks, and several advanced workflows are not implemented. See ROADMAP.
